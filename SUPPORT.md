# Support and Feedback

## Bug reports

Please use GitHub Issues for reproducible software or hardware-integration problems:

https://github.com/DirectorOfRisk/PMWinWingBridge/issues

Choose the **Bug report** form and include the requested environment details.
For USB, COM-port, display or LED problems, include the relevant section from
`Logs/bridge-*.log` whenever possible.

Before opening a bug report, please check that:

- Project Magenta and PMWinWingBridge use opposite ends of the intended virtual null-modem pair.
- No analyzer or other application has opened the bridge COM port.
- SimAppPro, CDUHUB, SPAD.neXt, MobiFlight or another application is not simultaneously controlling the same WinWing CDU.
- You are using the latest published PMWinWingBridge release.

## Feature requests

Use the **Feature request** issue form for concrete changes that could be implemented in PMWinWingBridge.

## Questions and general feedback

Use GitHub Discussions for setup questions, ideas, usage feedback, cockpit examples and other open-ended conversations:

https://github.com/DirectorOfRisk/PMWinWingBridge/discussions

GitHub Discussions must be enabled by the repository owner before this link becomes available.

## Privacy

Logs may contain device identifiers, COM-port names and local diagnostic
information. Review log excerpts before posting them publicly and remove any
information you do not want to share.
